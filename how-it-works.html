TrueDeals Shorts Uploader

An internal tool that uploads Damion Tucker's own product Shorts to his own YouTube channel, @TrueDeals79, using YouTube API Services.

The upload interface

There is no graphical interface and no sign-in page. The application is a command-line tool that runs on its operator's own computer, on a daily schedule. This page exists so a reviewer can see what that interface actually looks like.

1. The operator queues a video they made

Each entry in the local posting queue points at a video file on the operator's own machine, with the title and description the operator wrote: 

{
  "product":  "wolf-always-remember-lifestyle",
  "platform": "youtube_shorts",
  "media":    "record/wolf-always-remember-lifestyle/videoA/final.mp4",
  "title":    "Engraved wolf tee, always remember, close up on the print",
  "caption":  "Always remember the wolf in sheep's clothing...\n\nShop link is
               on my channel page. Tap my name to get there.\n\n#shorts",
  "link":     "https://www.etsy.com/listing/...",
  "status":   "queued"
}

2. The drain runs and uploads

On a schedule, the drain takes what is due and uploads it. This is the entire user-facing interface: 

> python -m workforce autopost-drain

instagram_reels posted: wolf-always-remember-lifestyle (id 18037...)
facebook_reels  posted: wolf-always-remember-lifestyle (id 12244...)
youtube_shorts  posted: wolf-always-remember-lifestyle (id dQw4w9WgXcQ)
  -> https://www.youtube.com/shorts/dQw4w9WgXcQ

3. Checking what is already live

A read-only command compares the channel's own uploads against the local queue, so nothing is ever posted twice. It uses only the API key, makes no writes, and needs no OAuth: 

> python -m workforce youtube-reconcile

channel holds 27 video(s); queue holds 91 youtube_shorts entries
46 already live, 8 ambiguous, 37 genuinely new
  LIVE  Funny cat shirt, rock paper scissors paw            -> MUUuPc5e_kI
  NEW   Engraved wolf tee, always remember, close up        -> (not yet posted)

dry run: nothing stamped.

4. The one write call

videos.insert is the only write the application makes. It uploads one video at a time, to the operator's own channel, and then reads the video back with videos.list to confirm what privacy status it came back with. Nothing else on YouTube is touched.

Revoking access

The operator can withdraw this application's access at any time from the Google security settings page, which immediately stops it being able to upload.
