TrueDeals Shorts Uploader

Privacy Policy — last updated 14 September 2026

What this application is

TrueDeals Shorts Uploader is a private, internal tool operated by Damion Tucker, a sole operator trading as TrueDealsDesigns. It uploads short videos of my own products to my own YouTube channel, TrueDeals79 (channel ID UCK-nscJZtU5dsIOb7dCyD0w), using the YouTube Data API v3.

It is not a public product. It is not distributed, sold, or offered to anyone else. It has exactly one user: me. Nobody else can sign in to it, and it runs only on my own computer.

Whose data it touches

The application authenticates as me, using my own Google account, and it acts only on my own YouTube channel. It does not access, request, read, or store data belonging to any other YouTube user, channel, or viewer.

Because there are no other users, the application collects no personal information from anyone. There is no sign-up, no account system, no analytics, no tracking, no cookies, and no third party the data could be shared with.

What it stores, and why

For each video it uploads to my own channel, the application keeps a local record of:

  • the YouTube video ID;
  • the video title and description I wrote;
  • the date it was published;
  • the public permalink, in the form https://www.youtube.com/shorts/{video_id}.

These describe my own uploaded videos. They are not information about a person. They are kept for one reason: so the tool does not upload the same video to my channel twice.

This record is stored in a file on my own computer. It is not uploaded anywhere, not published, and not shared with any third party.

Credentials

The application uses my own API key and my own OAuth 2.0 client credentials and refresh token, issued to my Google account. They are stored in a local environment file on my own machine, are not in source control, and are not shared with anyone. The OAuth token authorises the application to upload to my channel and nothing else.

API methods used

  • videos.insert — uploads one of my videos to my own channel. This is the only write call the application makes.
  • videos.list — reads back a video I have just uploaded, to confirm what privacy setting it came back with.
  • channels.list and playlistItems.list — read my own channel's uploads, so the tool can tell what is already posted before queuing anything new.

No other YouTube API methods are called. The application does not use search, comments, subscriptions, or analytics APIs, and does not scrape YouTube by any means.

Content

Every video uploaded is one I made myself: product photography and footage of my own products, or stock footage licensed from Pexels under its free licence, with credit and source recorded alongside the video files. No video contains content taken from another creator or another channel.

Advertising and links

The application displays no advertising. Video descriptions link only to my own Etsy shop, TrueDealsDesigns. There are no affiliate links and no links to any party I do not own.

YouTube API Services, and the policies that govern this tool

This application uses YouTube API Services. By using it, I am bound by the YouTube Terms of Service, and the data Google handles is governed by the Google Privacy Policy.

Authorisation granted to this application can be revoked at any time from the Google security settings page, which lists every application with access to a Google account and allows access to be withdrawn. Revoking access immediately stops this application from being able to upload anything.

Data retention and deletion

Since no data about any other person is collected, there is nothing for another person to request access to or deletion of.

The local records described above — video IDs, titles, publication dates and permalinks for my own uploads — are deleted whenever I delete them, and are deleted in full if I stop using the application. No stored YouTube data is retained beyond 30 days without being refreshed from the API, and any data that is not refreshed is discarded.
